
# 🚀 Personal Portfolio Website

 Check for the preview: https://anfas-kk.github.io/portfolio/

A modern, responsive personal portfolio website built using **HTML, CSS, and JavaScript**.
This portfolio showcases my projects, skills, qualifications, and contact functionality with real-time email integration.

---

## 🌟 Features

* 🌙 Dark / Light Mode Toggle
* 📱 Fully Responsive Design
* 📊 Animated Skill Progress Bars
* 📂 Projects Section with GitHub Links
* 🧩 JSON-based Services Section
* 📧 Real Contact Form using EmailJS
* 🔝 Back-to-Top Button
* 🎨 Clean UI with Smooth Animations

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Flexbox & Responsive Design)
* JavaScript (Vanilla JS)
* EmailJS (Contact Form Integration)
* Boxicons & FontAwesome
